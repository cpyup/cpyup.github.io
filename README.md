# Read Me

## Year Up United Clock

This is a timer/clock for use within the Year Up United(YUU) organization. Originally created by a YUU Alumnus, we have updated it with new features to streamline useablity and align with YUU rebrand. 

## Functionality Added:

- Ability to add target time rather than only create a timer.

- Option to start stopwatch.

- Ability to change timezone of user.

- Buttons to set the time, start, restart, Add Time and Pause the timer.

- A design that aligns with the rebrand for YUU.
